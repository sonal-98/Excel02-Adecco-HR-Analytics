# Excel02-Adecco-HR-Analytics

The Adecco HR Analytics project focuses on analyzing employee and HR-related data to identify workforce trends and generate useful insights for HR decision-making.

## Objectives

1. Analyze employee data
2. Understand workforce characteristics
3. Identify HR trends and patterns
4. Analyze employee-related KPIs
5. Support data-driven HR decision-making
6. Build meaningful visualizations and dashboards
   
## Key Analysis Areas
1. Employee demographics
2. Workforce distribution
3. Department/role analysis
4. Employee performance
5. Compensation-related analysis
6. Workforce trends
7. HR KPIs

## Excel Skills Used
1. Data Cleaning
2. Data Transformation
3. Excel Formulas
4. Pivot Tables
5. Pivot Charts
6. Conditional Formatting
7. KPI Analysis
8. Data Visualization
9. Dashboard Creation
